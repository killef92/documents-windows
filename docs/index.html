Everything you need, nothing in the way.

One small app for the documents you deal with every day. The page stays the star: sober interface, light and dark themes that follow Windows.

Open PDFs and photos

PDF, JPG, PNG, WebP and GIF in the same window, with page thumbnails to flip through.

Zoom, rotate, search

Find any word in a PDF, zoom in on details, turn pages the right way up.

Annotate

Highlight, shapes, arrows, text, notes and freehand drawing.

Fill in and sign

Type into PDF forms and add your signature, saved for next time.

Rearrange pages

Move, delete, rotate and merge pages, then export a smaller PDF.

Touch up photos

Crop, adjust colors, resize and flip your images.

Quick preview

Select a file in File Explorer and press Space to glance at it.

Private by design

Nothing about you or your files is sent anywhere. Your originals are only changed when you save.

Install in a minute.

A single installer, about 10 MB. It also works on Windows Server.

  1. Download Documents-setup.exeAlways the latest version, straight from GitHub.
  2. Run itIf Windows shows a blue “protected your PC” warning, click More info, then Run anyway: the installer isn't signed with a paid certificate yet.
  3. Choose “Only for me” or “For all users”Then Install. Documents can open your PDFs and images with a double click.

Updates on their own

Documents checks GitHub for new versions and offers to install them. Updates are signed and refused if the signature doesn't match.

Free and open source

MIT license. Every installer is built from the public source code by GitHub Actions. See the release.

Heads-up: vibe-coded

All of the code was written by an AI (Claude), guided and tested by a human who isn't a developer. It is used every day, but keep copies of important documents.
